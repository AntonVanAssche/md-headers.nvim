INTRODUCTION                                                *md-headers-intro*

Markdown Headers uses Neovim's Treesitter to provide fast and efficient
navigation between Markdown and HTML headings, with quick jumping, a heading
list, and full customization.

==============================================================================
COMMANDS                                                 *md-headers-commands*

                                                              *:MDHeaders*
:MDHeaders
:lua require('md-headers.controller').popup()

Opens a floating window listing all headings in the current buffer, with the
cursor on the first heading.

                                                       *:MDHeadersCurrent*
:MDHeadersCurrent
:lua require('md-headers.controller').popup(vim.api.nvim_win_get_cursor(0)[1])

Opens a floating window listing all headings, with the cursor focused on the
heading currently being edited.

                                                      *:MDHeadersQuickfix*
:MDHeadersQuickfix
:lua require('md-headers.controller').quickfix()

Toggles a quickfix window showing all headings in the current buffer (opens
on first call, closes on second).

                                                     *:MDHeadersTelescope*
:MDHeadersTelescope
:lua require('md-headers.controller').telescope()

See |md-headers-telescope| for more information.

==============================================================================
TELESCOPE INTEGRATION                                   *md-headers-telescope*

Markdown Headers provides a Telescope extension to quickly navigate to
headings in a Markdown file. This is useful for large files where headings
act as an outline. Requires `telescope.nvim` to be installed.

As any other Telescope extension, you can call it with the following command:

>
  :Telescope md-headers headings
<

However, the plugin provides an alias for this command:

>
  :MDHeadersTelescope
<

Both commands will open a Telescope picker showing all headings in the
current buffer, with their depth and text. Select a heading to jump to that
section. If no headings are found, a warning message is shown.

CONFIGURATION                                       *md-headers-configuration*

------------------------------------------------------------------------------
CONFIGURATION SETUP                           *md-headers-configuration-setup*

To override the default configuration: 
>lua
  require('md-headers').setup({
    width = 80,
    height = 15,
    borderchars = { "-", "|", "-", "|", "+", "+", "+", "+" },
    headerchars = { "(1)", "(2)", "(3)", "(4)", "(5)", "(6)" },
    popup_auto_close = false,
    highlight_groups = {
      title = { fg = "#FF0000" },
      border = { fg = "#00FF00" },
      text = { fg = "#0000FF" },
    },
  })
<

This setup example customizes the floating window size, changes the border
characters, changes the header depth icons, disables automatic popup closing,
and applies specific colors to highlight groups.

See |md-headers-configuration-options| for available options.

------------------------------------------------------------------------------
CONFIGURATION OPTIONS                       *md-headers-configuration-options*

The following options can be passed to |md-headers-configuration-setup|.

                                                        *md-headers-width*
width                                                           (number)
    Width of the floating window. ~
    Default: `60`

                                                       *md-headers-height*
height                                                          (number)
    Height of the floating window. ~
    Default: `10`

                                                  *md-headers-borderchars*
borderchars                                                     (table)
    Characters used for the window border. ~
    Default:
>lua
      { "─", "│", "─", "│", "╭", "╮", "╯", "╰" }
<

                                                  *md-headers-headerchars*
headerchars                                                      (table)
    Icons used for heading levels. ~
    Default:
>lua
      { "󰲡 ", "󰲣 ", "󰲥 ", "󰲧 ", "󰲩 ", "󰲫 " }
<

                                             *md-headers-popup-auto-close*
popup_auto_close                                               (boolean)
    Automatically close the popup after selection. ~
    Default: `true`

                                                  *md-headers-win-options*
win_options                                                    (table)
    Window options applied to the floating window. ~
    Default:
>lua
      {
        number = false,
        relativenumber = false,
        cursorline = true,
      }
<

                                             *md-headers-highlight-groups*
highlight_groups                                               (table)
    Highlight groups used by the popup. ~
    Default:
>lua
      {
        title  = { fg = nil, bg = nil },
        border = { fg = nil, bg = nil },
        text   = { fg = nil, bg = nil },
      }
<

------------------------------------------------------------------------------
                                *md-headers-configuration-recommended-keymaps*
CONFIGURATION RECOMMENDED KEYMAPS

This plugin does not provide any keymaps by default. Below are some
recommended keymaps to add to your configuration for a more accessible
experience.

>
  local map = vim.keymap.set

  map("n", "<leader>mh", "<cmd>MDHeaders<cr>")
  map("n", "<leader>mc", "<cmd>MDHeadersCurrent<cr>")
  map("n", "<leader>mq", "<cmd>MDHeadersQuickfix<cr>")
  map("n", "<leader>mt", "<cmd>MDHeadersTelescope<cr>")
<
